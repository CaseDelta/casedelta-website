CaseDelta

Set up your machine

One command, once. It takes between five and twenty minutes.

1

Open Terminal

Terminal is already on your Mac. Hold ⌘ and press space, type terminal, and press return.

A small black or white window opens. That is the right one. This is the only time you will use it.

2

Copy this, paste it in, press return

Click Copy, click once inside the Terminal window, press ⌘V, then press return.

bash -c "$(curl -fsSL https://casedelta.com/install.sh)"
Nothing to type. If the Copy button does not work, click the command once to select all of it, then press ⌘C.
3

Three things will happen. All three are expected.

  • 🔑 It asks for a password. This is the password you use to log into this Mac, not your CaseDelta one. Apple requires it to install their developer tools. Nothing is sent anywhere. You will not see the letters as you type, which is normal.
  • 🍎 A small Apple window appears. Click Install, then Agree, and leave it alone. The Terminal window carries on by itself when Apple has finished.
  • 🌐 Claude's download page opens in your browser. This happens only if you do not already have Claude. Download it, drag Claude into your Applications folder, then switch back to Terminal. It is waiting for you and continues on its own.
You do not need Homebrew. If anything tells you to install it, that is the wrong path. Close it and tell your manager.
When it says your Mac is ready
4

Open Claude and sign in

Open Claude from your Applications folder and sign in with the account your manager sent you.

5

Open your work folder

Click the Code tab at the top. Not Cowork, the Code tab. Choose Local, click Select folder, and pick rep-outreach-kit from your Desktop.

Claude may ask whether you trust this folder and whether to allow a browser connection. Say yes to both.

Local matters. Cloud runs Claude on a computer somewhere else, which cannot open your browser. If Claude ever says it is running on a Linux machine, this is the setting to change.

6

Say one sentence

Type this and press enter:

Run my setup.

Claude takes it from there and tells you when it is done. After that, starting work every day is one sentence: Start today's outreach run.

It said STOPPED

That is the setup telling you it could not finish, and it always says which step. Send your manager the line it printed, the one that starts with installer v. Do not try to fix it yourself and do not install anything it did not ask for.

Running the command a second time is always safe and usually finishes the job. If you are not sure whether it worked, run it again.

I already did this once

Then you are set up and there is nothing to redo. Open the folder you already have.

Running the command again will not create a second folder. It checks for the one you have and leaves it alone. You never need to download anything again to get an update, because the tools and the instructions refresh themselves every time you start a run.

Nothing happens when I paste

Click once inside the Terminal window first, so it is the window listening to your keyboard, then paste. Terminal does not always show the text as you paste it; press return anyway.

Before you start: LinkedIn Premium

This will not work on a free LinkedIn account. A free account allows only about three to five connection requests with a note per month, and every message this system sends has a note. Any Premium tier fixes it, including the cheapest one. Your manager sorts this out with you before your first run.

Read this first. The outreach tool itself does not run on Windows yet, so this will not get you sending. It sets up the Claude app and nothing more. Tell your manager you are on Windows.
1

Open PowerShell

Press the Windows key, type powershell, and press enter.

2

Copy this, paste it in, press enter

Click Copy, click once inside the PowerShell window, right-click to paste, then press enter.

irm https://casedelta.com/install.ps1 | iex

It installs Git, Chrome and the Claude app. If Windows asks to allow changes, say yes.

Stuck for more than a few minutes? Message your manager rather than trying things. Nothing here is urgent enough to guess at.
